# Portafolio de Diego Polo

Sitio estático creado con HTML, CSS y JavaScript, preparado para GitHub Pages.

## Publicar en GitHub Pages

1. Entra a https://github.com/diego-polo/diegopolo.github.io
2. Abre el repositorio y pulsa **Add file → Upload files**.
3. Descomprime el ZIP en tu computador y sube `index.html`, `style.css`, `script.js` y `README.md` (sube los archivos, no la carpeta que los contiene).
4. Pulsa **Commit changes** para guardar los cambios en la rama `main`.
5. En el repositorio, entra en **Settings → Pages**.
6. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y pulsa **Save**.
7. Espera unos minutos y visita https://diego-polo.github.io/diegopolo.github.io/ o el dominio de Pages que aparezca en la configuración.

## Antes de publicarlo

- Revisa que los nombres y enlaces de cada proyecto apunten a los repositorios correctos. Los botones de proyectos usan por ahora el listado general de repositorios.
- Añade una captura real de cada proyecto cuando puedas.
- No publiques tu dirección, teléfono personal, documentos, colegio ni otros datos privados.
- El texto dice que estás aprendiendo; cambia esa descripción a medida que desarrolles nuevas habilidades.

## Archivos

- `index.html`: contenido y estructura.
- `style.css`: diseño responsive y estilos.
- `script.js`: menú móvil y año automático.
