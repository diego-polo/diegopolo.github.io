# Portafolio de Diego Polo

Sitio personal estático creado con HTML, CSS y JavaScript, preparado para GitHub Pages.

## Actualizar el sitio publicado

1. Descomprime este ZIP en tu computador.
2. Entra al repositorio que publica tu portafolio en GitHub.
3. Pulsa **Add file → Upload files** y sube `index.html`, `style.css`, `script.js` y `README.md` en la raíz del repositorio.
4. Pulsa **Commit changes**.
5. Espera unos minutos y recarga el sitio. GitHub Pages publica los archivos de la rama y carpeta configuradas en Settings → Pages.

Documentación oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Antes de publicar

- Comprueba que los enlaces de tus proyectos llevan al repositorio correcto.
- El proyecto **El Reino de los Poemas** enlaza a https://el-reino-de-los-poemas.onrender.com
- Añade capturas reales de los proyectos cuando puedas.
- No publiques dirección, teléfono personal, documentos, colegio ni otros datos privados.
- Mantén las descripciones honestas: el portafolio presenta tu proceso de aprendizaje.

## Archivos

- `index.html`: contenido y estructura.
- `style.css`: diseño adaptable.
- `script.js`: menú móvil y año automático.
